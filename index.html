Session 4 • Active Lesson

Clean Algebra: Variables on Both Sides → Distribution in Equations

Main idea: the mathematics is getting more complicated, so organization matters more. Keep each new line directly under the previous line, simplify what can be simplified, preserve equality, and then solve.

How we work: paper first. Explain → demonstrate → work by hand → discuss reasoning → check → increase difficulty. Skip ahead as soon as mastery is obvious.

1. Learning Objectives

By the end of this session, Shivam will be able to:

  • keep multi-step algebra organized vertically so every step can be checked;
  • simplify expressions containing first- and second-degree terms and write them in standard form;
  • solve equations with the variable on one side and on both sides;
  • explain why the same operation must be applied to both sides of an equation;
  • recognize when distribution or combining like terms should happen before solving;
  • solve introductory equations containing distribution, including a negative outside factor;
  • check solutions by substitution into the original equation.
Organize→Simplify→Collect variables→Undo operations→Check

2. Warm-up Retrieval

Paper only. These are drawn directly from the skills used in the previous session. The purpose is to see what stayed secure, not to reteach everything.

  1. Simplify: -3x + 7x - 5
  2. Write in standard form: 2x² + 5x - x² - 3x + 4
  3. Solve: 5x + 4 = 29
  4. Solve: 7x - 6 = 3x + 14
  5. Solve: 8x + 3 = 5x + 18
  6. Preview: Solve if you see a path: 3(x + 2) + x = 18
Tutor checkpoint: #1–2 should be quick. #3–5 reveal equation fluency. Watch whether the work stays vertical and whether negative signs remain attached to their terms. Do not require #6 before direct instruction.

3. Direct Instruction

A. Clean work is part of the mathematics

As equations get longer, organization becomes a problem-solving tool. Put each equivalent equation directly below the previous one. One meaningful change per line makes errors easy to locate.

6x + 4 = 2x + 20
4x + 4 = 20
4x = 16
x = 4

Tutor cue: Ask Shivam to point to what changed from one line to the next. If he cannot name it, the line is probably doing too much at once.

B. Variables on both sides

6x + 4 = 2x + 20

There is no magic side the variable must live on. Choose a side, then use the same operation on both sides. Here, subtracting 2x leaves a positive coefficient:

4x + 4 = 20

Then subtract 4 and divide by 4:

x = 4

Key idea: “Move it across” is shorthand, not the mathematics. The mathematics is performing the same operation on both sides so equality remains true.

C. New connection: simplify before solving

Last session, distribution and equation solving were separate skills. Today we connect them.

3(x + 4) = 27

First simplify the side containing parentheses:

3x + 12 = 27
3x = 15
x = 5

Ask before writing: “What can become simpler before we start solving?” The desired habit is simplify first when needed, then solve.

D. Distribution plus variables on both sides

2(x + 5) + x = 4x + 1

Clean the left side first:

2x + 10 + x = 4x + 1
3x + 10 = 4x + 1
10 = x + 1
x = 9

Now a negative example:

-2(x - 4) = x + 11
-2x + 8 = x + 11
-3x = 3
x = -1

Emphasize: the negative sign belongs to the outside factor and must distribute to every term inside.

4. Guided Practice

There are 20 available problems. They are not a quota. Start where needed and skip forward when accuracy and explanation are secure.

A. Rapid retrieval — variable on one side

  1. 3x + 7 = 25
  2. 5y - 9 = 26
  3. 8a + 4 = 52
  4. 4m - 11 = 17
Move-on rule: If two consecutive problems are clean and Shivam can explain the inverse operations, jump to Part B.

B. Variables on both sides

  1. 5x + 6 = 2x + 21
  2. 7y - 4 = 3y + 20
  3. 9a + 2 = 5a + 30
  4. 4m + 15 = 6m + 3
  5. 8p - 5 = 3p + 30
  6. 2n + 17 = 5n - 4

Discussion prompt: “Which side would you collect the variable terms on, and why?” Accept either mathematically valid choice. Favor the choice that keeps the work easiest to read.

C. Distribution inside equations

  1. 3(x + 4) = 27
  2. 2(2y - 3) = 18
  3. 4(a - 2) + 3 = 23
  4. -2(m - 5) = 18
  5. 5(2p + 1) - 3 = 42
Pause before #14: Ask Shivam to predict the sign of the first distributed term and the constant term before multiplying.

D. Distribution + variables on both sides

  1. 2(x + 3) = x + 11
  2. 3(y - 2) + 4 = 2y + 9
  3. 4(a + 1) - 2 = 2a + 14
  4. -2(m - 3) = m + 9
  5. 3(2x + 1) + x = 4x + 18

Key question: “What needs to be cleaned up before this becomes an ordinary equation?” Reduce prompting once Shivam starts asking that question himself.

5. Independent Practice

Five problems, paper only. The goal is to see whether Shivam independently organizes, simplifies, solves, and checks without tutor sequencing.

  1. 7x + 5 = 3x + 29
  2. 4(2y - 1) = 28
  3. 3(a + 5) + 2a = 35
  4. -2(m - 4) + 3 = m + 14
  5. 5(2x - 1) + 2 = 6x + 17
Mastery evidence: 4/5 or better with clean vertical work, no repeated negative-sign mistake, and correct simplification before solving is enough to move forward. A self-corrected arithmetic slip is not the same as a structural error.

6. Decision Point

Extension A

Precision Repair

Use only the problem type matching the observed issue. Do not repeat all six.

  1. 6x + 7 = 2x + 31
  2. 5y - 3 = 2y + 18
  3. 3(a + 4) = 24
  4. -3(m - 2) = 15
  5. 2(x + 5) + x = 19
  6. 4(2p - 1) = 3p + 26

Repair method: identify the first incorrect line, model one parallel problem, then give control back immediately.

Extension B

Use Algebra to Model a Situation

If symbolic solving is secure, deepen understanding by creating the equation rather than simply solving one that is provided.

  1. Three times a number plus 4 equals 25. Write and solve an equation.
  2. Twice a number plus 7 equals the number plus 15. Write and solve an equation.
  3. A rectangle has width x and length x + 3. Its perimeter is 30. Write an equation and find both dimensions.
  4. Error detective: A student begins 4(x + 2) = 2x + 16 with 4x + 2 = 2x + 16. Identify the first error, correct it, and solve.

Discussion: Require Shivam to explain what each term represents. The goal is meaning, not just equation mechanics.

7. Exit Ticket

Complete without help. Keep the work directly underneath each previous line.

  1. 6x + 2 = 3x + 20
  2. 3(x + 5) = 27
  3. -2(x - 3) = x + 9
  4. In one sentence: Why should you simplify an equation before solving when parentheses or like terms are present?
8. Hidden Tutor Notes & Full Answer Key

Teaching priorities

  • Organization is the main process target: insist on top-to-bottom work, one meaningful change per line, and minimal side calculations.
  • Negatives: Shivam generally handles negative numbers well, but longer algebra makes sign loss easier. Treat the sign as part of the term.
  • Do not overpractice: if a block is mastered, jump ahead. Depth comes from explanation and transfer, not volume.
  • Variables on both sides: either side is mathematically valid. Help him choose the cleaner route rather than memorize “always move the smaller variable.”
  • New target: today is the first deliberate connection between distribution and solving equations. Build that bridge explicitly.
  • Check: substitute into the original equation, especially after negative distribution.

Anticipated misconceptions

Side-note drift

If calculations scatter around the page, stop and rewrite the last correct line underneath. Clean structure before continuing.

Negative sign dropped

Circle or underline the signed outside factor before distributing. Ask for the sign of each product before the number.

Solving before simplifying

Ask only: “Can either side become simpler first?” Then wait.

Changing only one side

Return to equality. Have Shivam name the operation performed to both sides.

Answer key

Warm-up: #1 4x − 5; #2 x² + 2x + 4; #3 x=5; #4 x=5; #5 x=5; #6 x=3.

Guided 1–4: x=6; y=7; a=6; m=7.

Guided 5–10: x=5; y=6; a=7; m=6; p=7; n=7.

Guided 11–15: x=5; y=6; a=7; m=−4; p=4.

Guided 16–20: x=5; y=11; a=6; m=−1; x=5.

Independent: x=6; y=4; a=4; m=−1; x=5.

Extension A: x=6; y=7; a=4; m=−3; x=3; p=6.

Extension B: #1 3x+4=25, x=7; #2 2x+7=x+15, x=8; #3 2x+2(x+3)=30, width=6 and length=9; #4 first error is failing to distribute 4 to both terms, correct equation 4x+8=2x+16, x=4.

Exit: #1 x=6; #2 x=4; #3 x=−1; #4 should explain that simplifying reveals the underlying equation and reduces the number of structures being managed while preserving equality.

Evidence to capture for Session 5

  • Warm-up #1–5 accuracy and whether any negative-sign error repeats.
  • Whether Shivam keeps work vertical without reminders.
  • Independent score out of 5.
  • Whether he independently simplifies before solving when parentheses are present.
  • Accuracy on variables-on-both-sides equations.
  • Accuracy when distribution and variables on both sides appear together.
  • Whether negative distribution changes his accuracy or pace.
  • Whether he checks solutions in the original equation without prompting.
  • If Extension B is reached, whether he can translate words/geometry into an equation and explain what each term means.
9. Hidden Parent Summary

Today Shivam continued building his algebra skills by solving equations with variables on both sides and then connecting equation solving to the distributive property. We emphasized keeping each step organized from top to bottom so longer problems are easier to follow and check. He also practiced simplifying expressions with first- and second-degree terms, writing standard form, and checking solutions by substitution.

The lesson was designed to move forward as soon as a skill was secure rather than requiring unnecessary repetition. The next session will be based on his accuracy, organization, and how independently he combines simplification with equation solving.
