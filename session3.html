Strong algebra is built by preserving equality, simplifying structure, and explaining why every move is legal.

Session 3 • Active Lesson

Simplify When Needed → Then Solve

Main idea: solving an equation is not moving symbols around. An equation says two quantities are equal. We preserve that equality while using legal operations to reveal the value of the variable.

How we work: the website coaches. The mathematics happens on paper. Explain → demonstrate → work by hand → discuss reasoning → check → increase difficulty.

1. Learning Objectives

By the end of this session, Shivam will be able to:

  • explain what an equation means and why equal operations on both sides preserve equality;
  • solve one-step and two-step equations using inverse operations;
  • recognize when an equation should be simplified before solving;
  • use distribution and combining like terms inside equations;
  • solve equations with variables on both sides when ready;
  • check a solution by substitution and explain whether it makes the original equation true.
Read the equation→Simplify if needed→Undo operations→Keep balance→Check

  2. Write 5 + 2x² - 3x + 4x² + x - 7 in standard form.
  3. 2(x + 4) + 3(x - 1)

Negative distribution

-2(x - 6)

Ask: “What signed term is the second term?” Then work -3(2a - 5).

Unlike terms / exponents

3x² + 4x - x² + 2x

Sort by variable part before doing any arithmetic.

Multi-step cleanup

3(x + 2) - 2(x - 4)

Use the order: distribute → combine → standard form.

3. Direct Instruction: What Does It Mean to Solve?

Expression

3x + 8

There is no equals sign and no single value of x to find. We can evaluate it for a chosen x or simplify it if possible.

Equation

3x + 8 = 20

This states that two quantities are equal. We are looking for the value of x that makes the statement true.

A. Equality is a balance

If A = B, adding, subtracting, multiplying, or dividing both sides by the same allowable number keeps the two sides equal.

x + 7 = 19

Subtract 7 from both sides:

x + 7 - 7 = 19 - 7

x = 12

Ask: “Why did we subtract 7 from both sides instead of just making the +7 disappear?” Expected idea: because the equality must stay balanced.

B. Inverse operations undo structure

Inverse operations reverse each other: addition/subtraction and multiplication/division.

3x + 5 = 20

Undo the +5 first: 3x = 15.

Then undo multiplication by 3: x = 5.

Check in the original: 3(5)+5=20. The left side becomes 20, so the solution is correct.

C. Simplify first when structure is hiding the equation

2(x + 4) + x = 17

First make the left side clearer:

2x + 8 + x = 17

3x + 8 = 17

Now solve: subtract 8 from both sides, then divide by 3.

x = 3

Core habit: Before solving, ask: “Can either side be simplified?” If yes, clean the structure first. Then use inverse operations while preserving equality.

4. Guided Practice

Work on paper. The set is intentionally longer than necessary so the tutor can skip ahead as soon as mastery is visible.

A. Rapid retrieval: one-step equations

  1. x + 8 = 21
  2. y - 6 = 15
  3. 5m = 35
  4. n ÷ 4 = 6
Checkpoint: If these are immediate and Shivam can name the inverse operation, skip directly to #5. Do not turn one-step equations into busywork.

B. Two-step equations

  1. 2x + 5 = 17
  2. 3y - 7 = 14
  3. 4a + 9 = 33
  4. 5m - 8 = 2
  5. 6p + 4 = 40

Discussion prompt: “Which operation is attached to the variable most directly? Which operation happened last to the expression?” Use the structure to justify the undo order.

C. Simplify first

  1. 2x + 3x = 25
  2. 4y - 2y + 6 = 18
  3. 3(x + 2) = 21
  4. 2(x + 4) + x = 17
  5. 5(2a - 1) - 3a = 23
Checkpoint: Before Shivam writes anything on #12–14, ask: “What can be simplified first?” If he identifies distribution/like terms without prompting, reduce tutor talk.

D. Distribution and variables on both sides

  1. 4(x - 1) + 2x = 20
  2. 3(2y + 1) - y = 18
  3. 2(x + 5) + 4 = 3x + 1
  4. 5(x - 2) + 3 = 2x + 11
  5. 4(2m - 3) - m = 2m + 8
  6. -2(x - 3) + 4x = 18

Key prompt: “Can you make each side simpler before deciding what to undo?” Avoid the phrase “move it to the other side.” Require the actual operation performed on both sides.

5. Independent Practice

Five meaningful problems. Paper only. No coaching unless Shivam is genuinely stuck. He should check at least two solutions by substitution.

  1. 7x - 5 = 30
  2. 3(x + 4) = 27
  3. 2(x + 5) + 3x = 30
  4. 4(2y - 3) - 2y = 24
  5. 3(x + 2) + 2(x - 4) = 2x + 19
Mastery evidence: Strong evidence is at least 4/5 correct, appropriate simplification before inverse operations, equations kept balanced, and a correct substitution check without being told how.

Extension B

Deeper Algebra: When Variables Appear on Both Sides

Choose this if: the independent set is secure and Shivam is explaining the balance logic without prompts.

Demonstrate

5x + 4 = 3x + 18

Subtract 3x from both sides: 2x + 4 = 18.

Subtract 4, then divide by 2: x = 7.

Check in the original equation before moving on.

Student works by hand

  1. 5x + 4 = 3x + 18
  2. 4(2y - 1) = 6y + 10
  3. 3(x + 2) + x = 2(x + 8)

Challenge: What if the variable disappears?

Sometimes simplifying both sides leaves a statement with no variable.

3(x + 2) = 3x + 6

Both sides simplify to the same expression, so every value of x works.

3(x + 2) = 3x + 5

This becomes 6 = 5, which is impossible, so no value of x works.

  1. 2(x + 4) = 2x + 8
  2. 4(x + 1) - 2x = 2(x + 2)
  3. 5(x - 1) = 5x + 2

8. Hidden Tutor Notes & Full Answer Key

Teaching cues

  • Evidence first: No Session 2 notes were supplied in the build prompt. Treat the warm-up as the live evidence gate. If #1–4 are secure, do not reteach expressions.
  • Language: Prefer “subtract 5 from both sides” over “move 5 across.” The first names the mathematics; the second hides it.
  • Simplify before solve: Ask the question, then allow silence: “Can either side be simplified?” Do not automatically announce the step.
  • Check by substitution: A solution is not just an answer. It is a value that makes the original equation true.
  • Pace: Skip problems aggressively when the reasoning is secure. The later blocks are available depth, not mandatory volume.

Anticipated misconceptions

“Move it across and change the sign.”

Ask what operation was actually performed to both sides. Rewrite one line showing that operation.

Solving before simplifying

If distribution or like terms remain, ask: “What can become simpler before we start undoing?”

Only changing one side

Return to the meaning of the equals sign. Have Shivam state what must remain true after each step.

Checking the simplified equation only

Substitute into the original equation so the entire chain of work is tested.
