# VT-Shivam

Adaptive five-session middle school math tutoring site.

## Included
- Student-facing welcome and five-session roadmap
- Session 1 algebra-readiness intake assessment
- Coverage of integer operations, order of operations, algebra vocabulary, combining like terms, signed terms, distributive property, one-step equations, two-step equations, and equation meaning
- Automatic scoring and domain-level proficiency profile
- Adaptive plans for Sessions 2–5 based on assessment results
- Local browser saving, printable results, answer review, and tutor planning notes

## Publishing
The site is contained in `index.html` and is ready for GitHub Pages from the `main` branch and repository root.
